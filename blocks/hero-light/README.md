# Hero Light

Text-only introduction for Our Accounts. Author a **Hero Light** table with an H1, supporting paragraphs and standalone CTA links in separate paragraphs. Rows and cells can be added or omitted; their content is combined in authored order.

| Hero Light |
| --- |
| H1: Our Accounts |
| Supporting copy with authored superscripts and inline links |
| Standalone link: See all pricing and rates |

The first standalone link becomes an outline button; later standalone links become secondary links. Inline links stay inside their paragraphs. Link destinations, heading IDs, rich text and disclosure references are preserved. Missing headings or CTAs remain usable.

Typography follows the reference: 48px/52px heading below 768px, 72px/76px from 768px; supporting copy is 15px/21px. The block stays left aligned. It shares the dark hero's 1200px container and 20px mobile/10px desktop inner gutters. An isolated imported paragraph repeating the heading immediately before the block is hidden; other surrounding content remains visible. Hero Light does not provide an image layout.

No DA table-name migration is required for the existing Accounts page.

Heading levels, link labels and disclosure references remain author responsibilities; the block preserves them instead of supplying campaign content.
