# Columns

One row of cells shown side by side from 900px and stacked below. A cell that contains only
a picture is treated as media; standalone link paragraphs become styled actions.

## Feature Grid

`Columns (Feature Grid)` is Planning's "Create a complimentary retirement plan". Put the
image, with an optional caption paragraph such as "Not yet a client? Open an account today",
in one cell. In the other cell, give each feature a heading followed by its copy. Each heading
and the content after it become one bordered card; from 900px the cards form a two-column
grid beside the image, and below 900px the features come first, then the image and caption.
A cell with fewer than two headings keeps its normal layout.
