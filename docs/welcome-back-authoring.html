Connect the market service

Market Data Base defaults to https://us.etrade.com/phx/pros/apicontent/market/. The implementation uses the direct PHX requests observed in the existing site's scripts, with credentials omitted. The existing site also batches its initial requests through /phx/pros/aggregate; this implementation uses the direct service endpoints.

OperationRequestResponse contract
Index / recent quotesPOST quote: {symbol:"DJIND,COMP.IDX,SPX,TNX",detailFlag:"INTRADAY"}quoteData[].product.symbol and intraday.lastTrade/changeClose/changeClosePercentage/dateTime. Timestamp availability must be confirmed from a live response.
ChartPOST chart: {indexes:"DJIND"}; also COMPIDX, SPX, TNXdata[0].dataPoints[].stockDate/highValue
Symbol lookupPOST lookup: {searchString:"query"}data[].symbol/description
Top fiveGET top5/TopDivYieldStocks, top5/MostSearchedMFs, top5/TopETFstop5Response.data[] and chartResponse.data[], aligned by position as in the current implementation

If these requests are blocked by CORS or gateway rules on the preview domain, configure an approved same-origin proxy and set Market Data Base to its root-relative base path, ending in a slash, such as /api/market/. The proxy must preserve the paths, POST bodies, methods, and response contracts above. Hosting a proxy is outside this repository's frontend-only deployment.

One-minute success caching shares requests within the page. Failures are retryable. Chart and list selections suppress late responses from older selections. Refresh fetches again. No service failure falls back to fabricated data. Missing values show unavailable text.

Treasury quote and chart prices are divided by 10, matching the current site. Changes remain as supplied by PHX. Verify this convention against live treasury values.
