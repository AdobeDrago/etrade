What caused the missing rates

The Bank row has valid Rate settings cells, but its four text markers use shorthand: {{psa-rate}} twice, {{checking-rate}}, and {{cd-rate}}. The renderer previously recognized only {{rate}} and {{rate:name}}. The settings were removed during decoration while the markers stayed visible, so no bank-rate request was made.

The renderer now also accepts shorthand when a matching Name is configured in that same row. Other placeholders stay authored. Prefer the explicit syntax for new content:

Existing markerPreferred markerMatching setting
{{psa-rate}}{{rate:psa-rate}}Name: psa-rate
{{checking-rate}}{{rate:checking-rate}}Name: checking-rate
{{cd-rate}}{{rate:cd-rate}}Name: cd-rate

Each Rate settings cell belongs in the same Tabs Accounts row as the panel copy. Put each setting in its own paragraph. Markers can appear in headings, descriptions and bold text; the replacement keeps links and superscripts.
